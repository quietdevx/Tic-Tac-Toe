 **Tic tac toe**

This is a Python project I made while learning Python.

- **Creates a terminal based game on tic tac toe.**

- **Features**

- Makes the computer not guess randomly and can counter blatant winning moves.
- Multiple functions which makes code reusable and clear
- Uses things like Try and Except and Casting to make the program run while handling user error.

- **What I learned**

- How to find items in a list by using indexes.
- Comparison using indexes
- Just good practice

- **How to run**

Download the files and run the file.

- **Made with**

Python

- **Future improvements**

- A scoring system
- Instead of only seeing obvious winning moves for the user, the computer can also see his own.
